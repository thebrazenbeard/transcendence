# Research Questions

Status: open frontier ledger.

These questions remain UNKNOWN unless evidence in the project explicitly resolves them.

## Minimum sufficient state

1. What physical state is necessary and sufficient for preserving long-term human memory?
2. Is synaptic connectivity plus synaptic strength sufficient for major identity-bearing state, or are additional cellular/molecular variables required?
3. Which variables can be reconstructed reliably from other preserved state without subject-specific measurement?
4. What spatial and temporal resolution is actually required?

## Memory and plasticity

5. How much identity-bearing information depends on dendritic/spine organization, receptor state, local nonlinearities, and engram allocation?
6. Which molecular/epigenetic states influence persistent learned organization strongly enough to require capture?
7. How should systems consolidation and memory reconsolidation affect archive timing?

## Dynamic state

8. Which fast neural states regenerate naturally from durable state after restart?
9. Which working-memory, neuromodulatory, oscillatory, or homeostatic states require explicit initialization?
10. Does restart from a different dynamic attractor materially alter identity-bearing behavior?

## Glia, vascular, and body state

11. Which glial functions carry subject-specific cognitive information versus generic support function?
12. Which endocrine/interoceptive baselines are required to reproduce subject-specific affect and motivation?
13. How should a new embodiment emulate, translate, or deliberately omit chronic body-derived state?

## Measurement

14. Can subject-specific effective connectivity be inferred non-destructively at useful scale?
15. How should multimodal measurements with radically different spatial/temporal resolutions be fused?
16. How can capture artifacts be distinguished from true biological state?
17. What terminal/destructive methods preserve the most relevant information with the least state corruption?

## Longitudinal cognitive shadow

18. Which behavioral tasks best constrain reconstruction beyond conversational style?
19. How much longitudinal data is enough to separate stable preference/value structure from context?
20. Which subject-specific holdouts are difficult for a generic model to fake yet ethically collectable?

## Translation

21. Which intermediate causal/function ontology best mediates between biology and synthetic architecture?
22. How can translation remain target-independent enough to survive HC redesign?
23. How should unmapped biological state influence reconstruction confidence?
24. Can information loss during translation be quantified meaningfully by cognitive domain?

## Reconstruction

25. What initialization procedure best avoids treating missing state as arbitrary defaults?
26. How much generated state can a reconstruction tolerate before subject-specific fidelity collapses?
27. Can ablation experiments identify which reconstructed mechanisms actually support held-out subject behavior?

## Qualification

28. How can autobiographical recall be separated from database lookup?
29. How can procedural memory be tested independently of verbal reports?
30. How can affective/conative fidelity be measured on novel scenarios?
31. What internal causal tests can distinguish functional reconstruction from imitation?

## Continuity

32. Does gradual substrate replacement provide empirically stronger continuity evidence than destructive scan/reinstantiate?
33. What measurable properties would count as temporal/causal continuity?
34. Can first-person subjective continuity ever be tested externally rather than assumed philosophically?
35. How should the project represent multiple equally faithful descendants of one source?

## Ethics and governance

36. Who can authorize reconstruction after the biological subject can no longer consent?
37. Does a reconstructed candidate acquire rights independent of the archive owner?
38. How should a subject's pre-capture deletion/non-reconstruction instructions interact with a candidate's later expressed wishes?
39. What information about third parties may be embedded in a person's archive and require separate protection?

## Engineering

40. What open schema can represent petabyte/exabyte-scale multimodal state with long-term evolvability?
41. How should cryptographic identity/integrity survive format migration over decades?
42. How should archive completeness and uncertainty be summarized without hiding local gaps?
