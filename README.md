# Transcendence

Transcendence is a working modular cognitive-architecture research repository.

The current `main` tree contains distinct areas for cognition, affect, salience/attention, memory, identity, semantics, pragmatics, behavior, routing, I/O, somatics, and runtime work.

## Current status

This repository previously displayed a copied **Hyperconnectome Brain** README that did not identify Transcendence correctly. This README now describes the repository that is actually present without promoting source into an installed or active runtime.

## Repository shape

The project is organized around separable subsystems, including:

- cognition and integration/arbitration;
- current and deep memory;
- salience, affect, homeostasis/interoception, and conation;
- self-identity, empathy, personification, and behavioral modeling;
- semantics, pragmatics, phonetics, speech, and adaptable I/O;
- routing, kinesis, optics, somatics, specifications, and runtime work.

## Evidence boundary

Repository source is evidence of implemented or explored architecture only. Installation, route selection, runtime consumption, behavioral qualification, and external effect require their own evidence.
